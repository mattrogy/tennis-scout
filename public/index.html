Tennis Scout

A scouting report on the player you will face: serve, return, pressure, head-to-head and tactical takeaways. Every number comes from tested code, never from the AI.

      Data: Jeff Sackmann (tennis_atp / tennis_wta), via the Aneeshers/tennis-sackmann-archive mirror, licensed CC BY-NC-SA 4.0. Non-commercial use; reports are shared under the same licence. ATP and WTA tour-level matches since 2015.

      How it works: sections 2 to 8 and 10 are written by code straight from the statistics. The AI model only writes short headlines without numbers; code checks each one and copies the verified facts under it. Source code (MIT licence).
